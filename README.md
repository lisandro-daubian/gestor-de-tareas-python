# 📝 Gestor de Tareas en Python (CLI)

Aplicación de consola desarrollada en **Python** diseñada para gestionar tareas cotidianas de manera eficiente y ordenada. Este proyecto forma parte de mi portfolio de desarrollo y práctica en programación, aplicando buenas prácticas como el manejo de excepciones, modularización con funciones y tipado estático.

---

## ✨ Características Principales

* **Creación de Tareas:** Permite registrar nuevas tareas validando que no estén vacías.
* **Visualización Dinámica:** Muestra el listado completo numerado, indicando el estado de cada tarea (`Pendiente` o `Completada`).
* **Contador de Estados:** Realiza un recuento automático de las tareas pendientes y completadas.
* **Gestión de Estados:** Permite marcar tareas como completadas o revertirlas a pendientes según sea necesario.
* **Eliminación Segura:** Remueve tareas de la lista seleccionándolas por su número correspondiente.
* **Manejo de Errores Robustez:** Control de excepciones (`ValueError`) ante entradas inválidas del usuario para evitar que el programa se cierre inesperadamente.
* **Tipado Estático:** Incorporación de *type hints* para mejorar la legibilidad y verificación estática del código.

---

## 🛠️ Tecnologías y Conceptos Utilizados

* **Lenguaje:** Python 3.13
* **Estructuras de Datos:** Listas y Diccionarios.
* **Control de Flujo:** Bucles (`while`), condicionales (`if-elif-else`).
* **Manejo de Excepciones:** Bloques `try...except`.
* **Buenas Prácticas:** Funciones modularizadas y tipado estático (*type hints*).
